# digitalwatermark 模块

本模块实现了数字水印的嵌入、提取及攻击测试，涵盖了空间域和变换域的主流算法，支持静态图像和 MP4 视频流。

## 核心算法

### 1. LSB 空间域水印 (`LsbWatermark`)
- **原理**：利用人眼对图像最低有效位（Least Significant Bit）不敏感的特性，将水印信息按位替换图像像素的 LSB。
- **实现**：支持在 YUV 空间的亮度平面（Luma）嵌入。

### 2. DCT 变换域水印 (`DctWatermark`)
- **原理**：将图像划分为 8x8 方块进行离散余弦变换（DCT），在其中频系数中通过调整大小关系嵌入水印。
- **特性**：相比 LSB，DCT 算法具有更好的**不可感知性**和**鲁棒性**（抵抗压缩、噪声等攻击）。

### 3. 视频水印管线 (`VideoWatermarkPipeline`)
- **原理**：基于 `MediaExtractor` 和 `MediaCodec`，对视频帧进行实时解码，在亮度平面逐帧（或隔帧）嵌入/提取水印后重新编码。
- **投票机制**：在视频水印提取时，采用**帧间多数投票**策略，提高水印恢复的准确率。

### 4. 鲁棒性评价与攻击仿真
- **攻击模拟**：提供高斯噪声、JPEG 压缩模拟、剪裁攻击等。
- **评价指标**：实现 PSNR（峰值信噪比）衡量不可感知性，NC（归一化相关系数）和 BER（误码率）衡量鲁棒性。

## 技术特点
- **盲提取**：提取水印时无需原始图像/视频，仅需含水印稿。
- **实时性**：优化了 DCT 变换路径，支持移动端流畅处理短视频。
