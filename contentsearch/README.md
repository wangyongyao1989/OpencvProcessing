# contentsearch 模块

本模块实现了**基于内容的图像检索（CBIR）**与视频检索功能，对应《数字图像与视频处理》第 10 章内容。

## 核心技术原理

### 1. 特征提取 (`ImageFeatures`)
- **颜色特征**：采用 **HSV 空间 3D 直方图**。将 H（色调）、S（饱和度）、V（明度）分别量化为 8x3x3=72 个区间，生成 72 维全局特征向量。
- **纹理特征**：采用**梯度方向直方图**。使用 Sobel 算子计算像素梯度，量化 18 个方向区间，反映图像的边缘分布和纹理结构。

### 2. 相似性度量
- **直方图相交法**：计算两个直方图的交集，衡量色彩分布的重合度。
- **余弦相似度**：衡量特征向量在多维空间中的方向一致性，对光照变化具有一定的鲁棒性。
- **综合权重**：通过加权融合（默认颜色 0.6 + 纹理 0.4）计算最终相似度评分。

### 3. 检索引擎 (`ImageSearchEngine` / `VideoSearchEngine`)
- **索引建立**：预先提取库中图像/视频关键帧的特征并存储。
- **Top-K 检索**：输入查询图，计算其与库中所有条目的相似度，按得分降序排列返回最接近的结果。
- **视频检索**：通过对视频进行关键帧采样，将视频匹配问题转化为关键帧集的特征匹配。

## 技术实现思想
- **降维量化**：通过 HSV 联合量化减少特征维数（72维），在保证区分度的同时提升匹配速度。
- **显著性加权**：纹理特征提取时仅统计梯度幅值大于均值的显著边缘，过滤噪声干扰。
