# imagerecognition 模块

本模块实现了图像识别的基本算法，包括基于模板匹配的 NCC 算法和基于几何特征的形状识别。

## 核心算法

### 1. 归一化互相关（NCC）模板匹配 (`NccMatcher`)
- **原理**：计算查询窗口与模板图像之间的归一化互相关系数。NCC 对线性光照变化（亮度增益和偏置）具有不变性。
- **金字塔加速**：采用**“粗到精”**的搜索策略。先在 1/4 分辨率下进行全图粗搜，确定候选区域后再在全分辨率下进行局部精细匹配，显著降低计算复杂度。
- **可视化**：支持生成相似度热力图（Similarity Map），直观展示匹配区域。

### 2. 形状识别 (`ShapeRecognizer`)
- **原理**：利用二值化图像的连通域，计算几何矩（矩、中心矩）和不变矩。
- **特征提取**：通过提取物体的**面积、周长、圆度、细长度**以及 **Hu 不变矩**进行分类识别。
- **不变性**：Hu 不变矩对图像的平移、缩放和旋转具有良好的不变性。

### 3. 视频识别管线 (`VideoRecognitionPipeline`)
- **原理**：在视频流中逐帧应用模板匹配或形状识别，并在 UI 上实时绘制检测框（Bounding Box）。

## 技术实现思想
- **效率平衡**：在移动端 CPU 上，通过下采样金字塔技术规避全图滑动窗口的巨大开销。
- **光照鲁棒性**：优先选择 NCC 而非 SAD/SSD，以应对视频拍摄中常见的光照波动。
