# qualityevaluation 模块

本模块用于图像和视频质量的客观评价，实现了《数字图像与视频处理》第 9 章中的质量评估体系。

## 核心功能

### 1. 失真模拟 (`ImageDistortions`)
- **噪声模拟**：提供高斯噪声、椒盐噪声生成。
- **模糊模拟**：提供运动模糊、高斯模糊效果。
- **亮度/对比度调整**：模拟采集过程中的光照失真。
- **JPEG 压缩模拟**：评估有损压缩对画质的影响。

### 2. 客观质量指标 (`ImageQualityMetrics`)
- **MAE/MSE**：计算原始图像与失真图像之间的平均绝对误差和均方误差。
- **PSNR (峰值信噪比)**：工程中最常用的全参考客观评价指标，以分贝（dB）为单位。
- **SSIM (结构相似度)**：从**亮度、对比度和结构**三个维度评估相似性。SSIM 比 PSNR 更好地契合了人类视觉系统（HVS）对图像结构的感知能力。
- **信息熵 (Entropy)**：计算图像的平均信息量，衡量图像内容的丰富程度。

### 3. 视频质量管线 (`VideoQualityPipeline`)
- **逐帧评估**：通过 `MediaExtractor` 提取原始视频和处理后视频的对应帧。
- **统计分析**：计算全视频所有帧的平均 PSNR 和 SSIM，并绘制质量波动曲线，用于分析编解码器或处理算法的稳定性。

## 技术实现思想
- **感知优先**：在评价结果中重点展示 SSIM，因为它能更准确地反映人眼对模糊、块效应等失真的厌恶感。
- **分块处理**：SSIM 算法采用 8x8 滑动窗口（或不重叠分块）计算局部统计量并求均值，保证了计算的鲁棒性。
