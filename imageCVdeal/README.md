# imageCVdeal 模块

本模块是整个项目的核心算法库，基于 **OpenCV** 使用 C++ 实现，复现了《数字图像与视频处理》教材中第 2 章至第 4 章的经典算法。通过 JNI 接口为 Android 层提供高效的图像处理能力。

## 核心功能与原理

### 1. 图像增强与变换（第 2 章）
- **灰度变换**：实现线性变换、反转变换、分段线性变换（对比度扩展）、削波处理、阈值化、对数变换及伽马变换。
- **直方图均衡化**：通过灰度分布映射，自动增强图像整体对比度。
- **平滑与去噪**：
    - 空间域：4-邻域/8-邻域平均、阈值邻域平均、中值滤波。
    - 频率域：理想低通滤波、高斯低通滤波。
    - 高级去噪：非局部均值（NLM）去噪。
- **锐化处理**：
    - 空间域：一阶梯度（HV差分、Roberts、Sobel）、二阶导数（拉普拉斯算子 H1/H6/H7）。
    - 频率域：理想高通、高斯高通滤波。
- **同态滤波**：在对数域对光照分量（低频）和反射分量（高频）进行差异化增益控制。
- **Retinex 增强**：实现 SSR（单尺度）、MSR（多尺度）及 MSRCR（带颜色恢复的多尺度）算法。
- **伪/假彩色增强**：灰度分层、灰度级彩色变换、假彩色合成。

### 2. 形态学图像处理（第 3 章）
- **二值形态学**：腐蚀、膨胀、开/闭运算、骨架抽取、细化、区域填充及内外边缘检测。
- **灰度形态学**：灰度腐蚀/膨胀、形态学梯度、Top-Hat/Bottom-Hat 变换。

### 3. 图像分割（第 4 章）
- **阈值分割**：迭代阈值、Otsu 最大类间方差法、自适应局部阈值。
- **边缘检测**：Canny 算子、LoG (Laplacian of Gaussian) 算子。
- **区域分割**：区域生长（自动选种）、分裂-合并、分水岭变换。
- **主动轮廓（Snake）**：基于能量最小化的贪心 Snake 算法、气球力 Snake、Chan-Vese 区域型主动轮廓模型。

## 技术实现思想
- **性能优化**：对于耗时较长的大尺寸高斯卷积（如 Retinex），采用**降采样加速策略**（Downsample -> Blur -> Upsample）。
- **稳定性**：通过 `JniHelper` 统一管理 Bitmap 与 `cv::Mat` 的内存转换。
- **数学对应**：代码注释中严格对应教材中的公式编号（如式 2-1, 4-10 等），便于学术参考。
